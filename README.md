# Web-Design-Project-Repository
A repository for a project in my Web Design class.
The purpose of the website is to be an e-commerce site for desk accessories and workspace organization products.
For the first week (so as of today) I set up the foundation of the website, and established the concept for the website.
For the second week, I will establish the initial visual design, as well as the product browsing experience.
For the third week, I will establish javascript coding and create checkout and contact forms.
For the fourth week, I will finish making the shopping cart page, as well as set up the inventory and cart systems.
Lastly, for the fifth week, I will make a network connection to test the page, as well as bug test to ensure no issues.
